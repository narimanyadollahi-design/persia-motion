# Changelog
## 1.0.0
- First public release: intake → story → approval gate → build; 7-beat Persian reel engine.
## 1.1.0
- `--template` option; design-per-story principle; example `story-detail-macro`.
## 1.2.0
- `scripts/music.py` synthesized Persian-mode music bed; two-pass mix with sidechain ducking; `pad`/`music_volume` options; portrait end card; pronunciation via diacritics.
## 1.3.0
- `scripts/sfx.py`: per-element synthesized sound design (typing, shutter, lock, stamp, flip, tick, ding, buzz…); mix uses `out/sfx.wav`.
- Laptop-keyboard typing sound (key-down + key-up clicks). `hold` per-line pacing; variable number of lines in custom templates; CTA end card pattern. Example story: florist "one photo, twelve occasions".
